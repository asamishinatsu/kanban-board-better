# Kanban Board Better

Pet-проект kanban доски.

Фронтенд: React+Typescript.

Бэкенд (планируется): Node.js.

## Установка

Из корня проекта:

```sh
npm install
```

## Команды

Все команды выполняются из корня проекта. Prettier и Oxlint проверяют
как фронтенд, так и файлы будущего бэкенда.

| Команда                | Действие                                               |
| ---------------------- | ------------------------------------------------------ |
| `npm run dev`          | Запустить фронтенд на `127.0.0.1` и свободном порту    |
| `npm run build`        | Проверить TypeScript и собрать фронтенд в `dist`       |
| `npm run preview`      | Посмотреть собранный фронтенд                          |
| `npm run lint`         | Проверить код с помощью Oxlint                         |
| `npm run lint:fix`     | Применить безопасные автоматические исправления Oxlint |
| `npm run format`       | Отформатировать файлы с помощью Prettier               |
| `npm run format:check` | Проверить форматирование без изменения файлов          |
